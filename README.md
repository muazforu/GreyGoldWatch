## 🚀 Run it

Just open `index.html` in a browser — or serve it:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 🛠️ Tech

Pure HTML + CSS + vanilla JS. The 3D viewer is CSS-3D based, the ambient
background is canvas 2D. Everything is inlined in one file.
